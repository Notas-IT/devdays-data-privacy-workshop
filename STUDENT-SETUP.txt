STUDENT WORKSHOP

Run commands from the repository root. Requires Docker Compose and Python 3.
The teacher branch contains the completed implementations.

Database fixtures:
docker compose -f database-workshop/docker-compose.yml up -d --wait postgres
docker compose -f database-workshop/docker-compose.yml exec -T postgres psql -v ON_ERROR_STOP=1 -U workshop -d privacy_workshop -f /workshop/schema.sql
docker compose -f database-workshop/docker-compose.yml exec -T postgres psql -v ON_ERROR_STOP=1 -U workshop -d privacy_workshop -f /workshop/load_data.sql

The administrator is provided for setup. Students must implement restricted
users, views, grants, row policies, and tests during the database exercises.

Presidio baseline and acceptance tests:
docker compose -f presidio-workshop/docker-compose.yml build presidio
docker compose -f presidio-workshop/docker-compose.yml run --rm presidio
Custom detection is intentionally unfinished; implement it to pass the tests.

Raw log sources:
sh log-pipeline-workshop/snippets/pulse-logs.sh

First log-processing exercise:
docker compose -f log-pipeline-workshop/docker-compose.yml run --rm processor
This intentionally raises NotImplementedError until starter.py is implemented.
Implement and test batch sanitisation, then add Fluent Bit and Presidio services.
The process-logs snippets describe the later pipeline, not the starting state.

Schema-refresh databases:
sh schema-refresh-workshop/snippets/check-startup.sh
docker compose -f schema-refresh-workshop/docker-compose.yml run --rm refresh-runner python seed.py
bash schema-refresh-workshop/snippets/clone-pseudo-prod.sh

Implement identifier tokenisation, masking, schema description/comparison,
linkage checks, refresh orchestration, and their tests. The preserved snippets
show the expected commands and interfaces; exercise commands require the
corresponding student-created files. starter.py is intentionally unfinished.
The initial clone copies raw synthetic fixtures; it does not sanitise them.

Agent-security baseline:
docker compose -f agent-security-workshop/docker-compose.yml up -d --build --wait

This is an intentionally unrestricted lab baseline. Students implement process,
filesystem, host and network restrictions, a gateway, restricted database
access, aggregates, authentication, audit logging, and a model proxy.
The baseline agent image provides Python and a PostgreSQL driver only; install
the selected agent CLI as part of the exercise. Use synthetic lab data only.

No agent instruction files or completed security implementations are supplied.
